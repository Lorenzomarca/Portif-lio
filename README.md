### 📌 Sobre o Projeto
Este repositório contém o código-fonte do meu **Portfólio Pessoal**, desenvolvido puramente com tecnologias web nativas para expor meus projetos e evolução técnica no curso do SENAI.

### 🎨 Recursos e Funcionalidades
*   ⚙️ **Style Engine:** Painel para mudar a cor de destaque e a fonte em tempo real (salva no `localStorage`).
*   🌓 **Dark/Light Mode:** Alternância nativa de tema visual.
*   🖱️ **Cursor Custom:** Efeito magnético e interativo que reage a botões e links.
*   ✨ **Hover Glow:** Efeito neon nos cards que acompanha o movimento do mouse.
*   🎬 **Scroll Animado:** Revelação suave de seções usando *Intersection Observer API*.

### 🛠️ Tecnologias
*   HTML5 (Estrutura Semântica)
*   CSS3 (Variables, Grid, Flexbox, Fractal Noise)
*   JavaScript ES6+ (Manipulação de DOM e Persistência)
*   React e UX/UI (em estudo)

### 📂 Arquivos do Repositório
*   `index.html` ➔ Estrutura das telas, seções e modais.
*   `style.css` ➔ Temas, variáveis dinâmicas e responsividade.
*   `script.js` ➔ Lógica do cursor, personalização de layout e animações.
